# Antigravity MCP Orchestrator — Brand Guidelines

## Brand Overview
Antigravity MCP Orchestrator is a Model Context Protocol server connecting Google Gemini and local developer workflows to Google Antigravity IDE.

## Logo Architecture
- The Orbital Delta: Monolithic aerospace delta canopy enclosing an upward levitating diamond core spark.
- Dark Canvas Variant: Pure White canopy (#FFFFFF) with Vivid Crimson Red spark (#EF4444).
- Light Canvas Variant: Jet Black canopy (#0A0A0A) with Crimson Red spark (#DC2626).

## Color Palette
| Swatch | Name | HEX | RGB | Use Case |
|---|---|---|---|---|
| Black | Jet Black | #0A0A0A | rgb(10, 10, 10) | Primary canopy (light mode), backgrounds |
| Crimson | Vivid Red | #DC2626 | rgb(220, 38, 38) | Levitating spark, primary accent |
| Crimson Glow | Signal Red | #EF4444 | rgb(239, 68, 68) | Dark mode accent, active states |
| White | Crisp White | #FFFFFF | rgb(255, 255, 255) | Canopy in dark mode, light text |

## Typography
- Display: VT323 (Google Fonts) — Arcade, retro-futuristic titles
- Body / Code: JetBrains Mono — High-readability technical copy
